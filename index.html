PhishGuard AI

PhishGuard AI is an email security project designed to help users identify potentially malicious or phishing emails. It combines rule-based analysis with optional AI-assisted risk assessment and link checking to highlight suspicious messages.

The project explores how automation and AI can support phishing detection while helping users understand why an email may be risky.

What I learned: Email analysis, API integration, risk classification, application development, and security-focused design.

02

Network Intrusion Detection System

I developed a Python-based network monitoring tool that analyzes packets and generates alerts when traffic matches defined suspicious activity patterns.

The prototype includes detection rules for potential port scanning, ICMP flooding, and SSH brute-force attempts. It records security alerts with timestamps and supporting details in a JSON log for later review.

What I learned: Packet analysis, TCP/IP fundamentals, detection logic, network monitoring, and structured security logging.

This is a learning prototype, not a production-ready intrusion detection platform.

  • Python
  • Scapy
  • Wireshark
  • Network security

Phishing Detection Web Application

This project explores how a web application can assess suspicious emails and URLs using rule-based checks and machine learning models.

It evaluates indicators such as unusual links, urgency-related language, and requests for sensitive information, then presents the results to the user.

What I learned: Basic machine learning integration, web application development, input analysis, and security risk indicators.

The models use a small set of example data, so the results should be treated as experimental rather than as proof that a message or URL is safe or malicious.

  • Python
  • Flask
  • Scikit-learn
  • SQLite

Reinforcement Learning for Adaptive Intrusion Detection

This academic research area explores how reinforcement learning could help an intrusion detection system adapt its decisions to changing network conditions.

The goal is to investigate how a learning-based approach might improve detection decisions and help manage false positives. The public repository currently contains an early-stage scaffold, so the adaptive detection and training components are not yet fully implemented.

Academic project under the CyberChef-Aidoo GitHub account. I am not the sole author, and the only public commit author on the repository is that account.

Research interests: Adaptive threat detection, reinforcement learning, network security, and reducing false positives.
